# Worked example — NOT research data

A teaching example showing what a completed ground-truth worksheet looks like
and how the rationale column should read.

**This schema is invented and is used nowhere in the research.** It is not in
`data/dev/` or `data/heldout/`, it is never passed to the grid search, the
calibrator or the ablation runner, and `discover_schemas()` will not find it.
Deleting this directory changes nothing about the artefact or its evaluation.

It exists so the pattern is visible without anchoring any real decision.
